# JavaScript Fundamentals Quiz

## Description

This project is a beginner-friendly quiz application built using HTML, CSS, and JavaScript.

The quiz displays one question at a time and allows users to test their knowledge of JavaScript fundamentals. Questions are randomized each time the quiz starts, and users can review their answers after finishing.

## Features

- Start screen before beginning the quiz
- Randomized question order
- Multiple-choice questions
- One question displayed at a time
- Score tracking
- Review of user answers at the end
- Restart quiz functionality
- Simple and professional layout

## Technologies Used

- HTML
- CSS
- JavaScript

## How to Run the Project

1. Download or clone the repository.
2. Open the project folder.
3. Open `index.html` in a web browser.
